# HostBrr StorageBox Knowledge Base

Diese Wissensdatenbank sammelt technische Informationen, Howtos, Erfahrungswerte und eigene Tests zur **HostBrr StorageBox**.

## Qualitätsstufen

| Status | Bedeutung |
|---|---|
| `official` | durch HostBrr dokumentiert |
| `community-reported` | Community-Bericht, noch nicht selbst geprüft |
| `verified` | praktisch selbst getestet |
| `deprecated` | veraltet oder ältere Produktgeneration |

## Themen

1. Grundlagen und Produktarchitektur
2. DirectAdmin, SSH, SFTP und Zugang
3. Backup mit rsync, rclone, Restic, Borg und Proxmox
4. Mounts unter Linux und Windows
5. Anwendungen wie Nextcloud und WebDAV
6. Sicherheit und clientseitige Verschlüsselung
7. Performance und reproduzierbare Benchmarks
8. Troubleshooting

## Arbeitsweise

Aussagen aus Foren werden nicht ungeprüft zu Fakten erklärt. Relevante Fundstellen werden zunächst unter `sources/` dokumentiert. Daraus entstehen konsolidierte Artikel unter `docs/`. Eigene Tests landen zusätzlich unter `tests/`.
