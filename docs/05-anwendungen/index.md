# Anwendungen

Anwendungen und Dienste, die direkt oder indirekt mit der StorageBox genutzt werden können.

## Geplante Themen

- Nextcloud direkt auf der StorageBox
- Nextcloud auf VPS mit StorageBox als Datenspeicher
- WebDAV
- statisches Hosting und Downloads
- Grenzen von Shared Hosting gegenüber VPS/Root-Server
