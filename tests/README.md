# Eigene Tests

Dieser Bereich enthält reproduzierbare Tests der HostBrr StorageBox.

## Struktur

- `benchmarks/` – Transfer-, Latenz- und I/O-Messungen
- `compatibility/` – getestete Programme, Protokolle und Versionen

## Mindestangaben je Test

- Datum
- StorageBox-Tarif/Generation
- StorageBox-Standort
- Quellsystem und dessen Standort/Anbindung
- Betriebssystem
- Tool und Version
- vollständiger relevanter Befehl ohne Secrets
- Ergebnis
- Besonderheiten/Limitierungen

Zugangsdaten und Schlüssel werden niemals committed.
